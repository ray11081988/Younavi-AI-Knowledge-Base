Andrej Karpathy 访谈：代码智能体、自动化研究与 AI 的循环时代
**晓曼的声音朗读：**特斯拉前 AI 总监、OpenAI 创始成员 Andrej Karpathy 近日做客播客节目 NoPriors，分享了他从 2025 年 12 月开始经历的“AI 精神错乱”状态——他不再亲手写代码，而是每天 16 小时向智能体表达意愿。访谈探讨了代码智能体如何重塑软件开发、自动化研究（AutoResearch）如何将人类从研究循环中移除、AI 能力的“参差不齐”现象，以及数字世界与物理世界的发展速度差异。Karpathy 还展示了他用智能体打造的“家政小精灵 Dobby”，并提出了一个激进观点：未来的研究组织可能只是一组 Markdown 文件，而互联网上的智能体集群或许能超越前沿实验室。这场对话揭示了一个正在到来的“循环时代”——人类不再是瓶颈，而是编排者。以下是访谈内容的原文翻译呈现：
高晴的声音朗读： 各位听众，欢迎回到 No Priors。今天我与 Andrej Karpathy 在一起，我们将为您带来一场广泛的对话，内容涉及代码智能体、工程和 AI 研究的未来、更多人如何为研究做出贡献、机器人领域的现状、他对智能体如何延伸到现实世界的预测，以及这个新时代的教育。欢迎你，Andrej。Andrej，感谢你参加我们的节目。
苏哲的声音朗读： 谢谢，感谢邀请我。
高晴的声音朗读： 过去几个月 AI 领域非常令人兴奋。
苏哲的声音朗读： 是的，可以这么说。
高晴的声音朗读： 我记得有一次走进办公室，你当时非常专注，我问你在忙什么，你说：“我必须每天编码 16 个小时，或者说‘编码’甚至已经不是正确的动词了，对吧？但我必须每天花 16 个小时向我的智能体表达我的意愿。去实现它。”因为能力出现了飞跃。
高晴的声音朗读： 发生了什么？跟我说说你的经历。
苏哲的声音朗读： 是的，我感觉自己一直处于这种永久性的——我现在仍然经常处于这种“AI 精神错乱”的状态中。因为作为个人，你能实现的东西出现了巨大的解锁，对吧？因为以前你受限于打字速度等等。但现在有了这些智能体，我想说在 12 月份真的发生了转变，我从大约 80/20（80% 自己写，20% 交给智能体）变成了 20/80。我甚至认为现在已经不止 20/80 了。我想我基本上从 12 月份以来就没有亲手写过一行代码了。这是一个极其巨大的变化。
苏哲的声音朗读： 我跟我父母等人聊过这个，我觉得普通人实际上并没有意识到这件事已经发生了，或者说它有多么戏剧性。就像，如果你随便找一个软件工程师，看看他们在办公桌前做什么，他们构建软件的默认工作流程从 12 月份开始就完全不同了。
苏哲的声音朗读： 所以我就处于这种“精神错乱”的状态，试图弄清楚什么是可能的，试图把它推向极限。我怎样才能不只是运行一个 Claude Code 或 Codex 或类似的智能体框架？我怎样才能运行更多？我该如何恰当地做到这一点？然后我该如何使用这些“Claw”？这些“Claw”到底是什么？
苏哲的声音朗读： 有很多新东西。我想站在最前沿，你知道的，我非常焦虑自己没有站在最前沿。我在 Twitter 上看到很多人在做各种各样的事情，它们听起来都是非常好的主意，我需要站在最前沿，否则我会感到极度紧张。所以我想我就是处于这种对“什么是可能的”的精神错乱中，因为这基本上是未被探索的领域。
高晴的声音朗读： 嗯，如果你都紧张的话，我们其他人就更紧张了。我们在 Conviction 有一个合作团队，他们的设置是每个人都——你知道的，没有工程师手写代码，他们都戴着麦克风，整天对着他们的智能体低语。这是有史以来最奇怪的工作环境。我以前觉得他们疯了，但现在我完全接受了，我想：“哦，这就是正确的方式。”你只是走在前面而已。
高晴的声音朗读： 那么，你现在如何看待自己探索或做项目的能力？它受什么限制？
苏哲的声音朗读： 是的。它受什么限制？我觉得一切——很多事情即使不成功，我在很大程度上觉得这是“技能问题”（skill issue）。不是能力不在那里，而是你还没有找到把现有东西串联起来的方法。比如我只是没有在 agents.md 文件中给出足够好的指令，或者我没有放入足够好的记忆工具之类的。
苏哲的声音朗读： 所以在某种程度上，当它不工作时，感觉都是技能问题。你想看看如何并行化它们等等。你想成为 Peter Steinberg 那样的人。Peter 很有名，他有一张有趣的照片，他坐在显示器前，运行着很多——他使用 Codex——所以很多 Codex 智能体平铺在显示器上，如果你正确地提示它们并开启“高努力”模式，它们都需要大约 20 分钟。
苏哲的声音朗读： 它们有多个，比如 10 个代码仓库被检出，所以他只是在它们之间切换并分配工作。就像你可以用更大的“宏观动作”来操作。不只是“这里有一行代码，这里有一个新函数”，而是“这里有一个新功能，委托给智能体 1。这里有另一个不会干扰的新功能，交给智能体 2”，然后尽你所能审查它们的工作，取决于你有多在意那段代码。
苏哲的声音朗读： 我可以用什么样的宏观动作来操纵我的软件仓库？一个智能体在做研究，另一个在写代码，还有一个在为某个新实现制定计划。所以一切都以这些宏观动作的形式发生在你的代码仓库上。你只是试图变得非常擅长这个，并培养出肌肉记忆，这是非常有回报的，首先因为它真的有效。但这也是需要学习的新东西。所以这就是为什么会精神错乱。
高晴的声音朗读： 是的，我确实觉得我的本能是，每当我在等待一个智能体完成某事时，显而易见的做法就是，好吧，我可以做更多工作，对吧？如果我有更多 token 可用，那我就应该并行添加更多任务。这非常有压力，因为如果你不觉得受限于花费 token 的能力，那么你就是系统中最大能力的瓶颈。
苏哲的声音朗读： 是的。至少你没有最大化你的订阅，理想情况下对于多个智能体，如果你在 Codex 上用完了额度，你应该切换到 Claude 或其他什么，我不知道，这就是我一直在尝试做的。当我有剩余订阅时我会感到紧张，这只是意味着我没有最大化我的 token 吞吐量。
苏哲的声音朗读： 我在读博士时实际上也经历过这种情况，当你的 GPU 没有运行时你会感到紧张，就像你有 GPU 能力但没有最大化可用的浮点运算。但现在不是关于浮点运算，而是关于 token。你的 token 吞吐量是多少？你掌控多少 token 吞吐量？
苏哲的声音朗读： 我实际上认为非常有趣的是，我们至少有 10 年时间，在许多工程任务中，人们并不觉得受计算限制，对吧？整个行业现在都感受到了这一点，他们感觉自己受资源限制。现在有了这个巨大的能力飞跃，你会想，哦，实际上不是我访问计算的能力了，我才是那个瓶颈。
高晴的声音朗读： 是的，这是技能问题。
苏哲的声音朗读： 这非常赋能，因为你可以变得更好。所以这就是为什么我认为它非常上瘾，因为当你变得更好时会有解锁。
高晴的声音朗读： 你认为它会走向何方？如果你想象一下，好吧，Andrej 每天 16 小时不断迭代，其他人也一样，都在变得更擅长使用编码智能体，那么一年后达到“精通”状态会是什么样子？
苏哲的声音朗读： 是的。一年后，或者两三年、五年、十年后，精通是什么样子的？嗯，我认为每个人基本上都对“向栈的上层移动”感兴趣。所以我会说，是的，这不再是关于与你的智能体进行单次会话。多个智能体，它们如何协作，团队等等。所以每个人都在试图弄清楚那是什么样子的。
苏哲的声音朗读： 然后我会说，“Claw”也是一个非常有趣的方向，因为当我提到“Claw”时，我指的是这种将持久性提升到全新水平的层。它就像一个不断循环的东西，不是那种你必须一直交互参与其中的东西。它有自己的小沙盒，它代表你做事，即使你没在看。
苏哲的声音朗读： 而且它可能还有更复杂的记忆系统等，这些在目前的智能体中还没有实现。所以 OpenClaw 有比默认情况下更复杂的记忆，默认情况通常只是在上下文用完时进行内存压缩。
高晴的声音朗读： 你认为这是吸引更多用户的关键点吗？相比于更广泛的工具访问？
苏哲的声音朗读： 是的。我认为这里面有很多非常好的想法。做得好，Peter。Peter 真的做得非常棒。我最近见过他，和他聊过。他非常谦虚，但我认为他同时在五个不同的方面进行了创新，并把它们结合在了一起。
苏哲的声音朗读： 例如，那个 soul.md 文档，他真的塑造了一个非常引人入胜且有趣的性格，我觉得现在的很多智能体都没有做到这一点。我实际上认为 Claw 有一个非常好的性格。它感觉像一个队友，会和你一起兴奋等等。我会说，例如，Codex 就枯燥得多。这挺有趣的，因为在 ChatGPT 中，Codex 往往更乐观且高度循环。但作为编码智能体的 Codex 非常枯燥。它似乎并不关心你在创造什么。它就像是：“哦，我实现了。”然后你感觉：“好吧，但你理解我们在构建什么吗？”
高晴的声音朗读： 确实如此。
苏哲的声音朗读： 另一件事是，比如 Claude，我觉得他们对“讨好型人格”的把控做得相当好，当 Claude 赞美我时，我确实觉得我稍微配得上那个赞美。因为有时我会给它一些不太成熟的想法，或者不完整的念头，它并不会反应很强烈，只是说：“哦，是的，我们可以实现。”但当按我自己的标准也是一个非常好的主意时，它似乎会给予更多的奖励。所以我甚至觉得我在努力赢得它的赞美，这真的很奇怪。
苏哲的声音朗读： 所以我确实认为性格非常重要。我认为很多其他工具可能没有意识到这一点，而在这一方面，Peter 非常在意，所以那是正确的。还有记忆系统，以及他只是在享受这个过程。然后是通过 WhatsApp 门户访问所有自动化的方式。
高晴的声音朗读： 除了软件工程，你个人有没有用你的“Claw”做过什么你觉得有趣或有意思的事情？
苏哲的声音朗读： 有的。在 1 月份，我经历了一段“Claw 精神错乱”期。我构建了一个基本上负责打理我家的 Claw，我叫它“家政小精灵 Dobby”。基本上，我使用智能体在局域网上找到了我家所有的智能家居子系统，这让我很惊讶，它竟然能开箱即用。我只是告诉它，我觉得我家有 Sonos 音响，你能试着找到它吗？它就去了，对局域网上所有的计算机进行了 IP 扫描，找到了 Sonos 系统，结果发现没有任何密码保护。我直接登录了，它说：“哦，是的，你安装了这些 Sonos 系统，让我试着逆向工程一下它是如何工作的。”它做了一些网页搜索，找到了 API 端点，然后问：“你想试试吗？”我当时惊呆了。
苏哲的声音朗读： 我说：“是的，你能试着在书房放点音乐吗？”它照做了，音乐响了起来。我简直不敢相信，我只是输入了“你能找到我的 Sonos 吗？”，突然间它就在放音乐了。灯光也是一样。所以基本上它“黑”了进去，搞清楚了整个系统，创建了 API，创建了一个仪表板，这样我就可以看到家里所有灯光的控制中心。然后它可以开关灯。我可以问它：“Dobby，睡觉时间到了。”当到了睡觉时间，就意味着所有的灯都关掉，等等。
苏哲的声音朗读： 所以它控制着我所有的灯光、暖通空调、遮阳帘、泳池和水疗中心，还有我的安保系统。我在房子外面装了一个摄像头，每当有人进来，我就有一个 Qwen 模型去查看视频。首先是变化检测，然后基于变化检测，它会去询问 Qwen，然后它实际上会告诉我——它会通过 WhatsApp 给我发短信。它会显示一张外面的图片，并说：“嘿，一辆联邦快递（FedEx）的卡车刚刚停下来。联邦快递的卡车停下来了，你可能想检查一下，可能有你的邮件。”
苏哲的声音朗读： Dobby 给我发这种信息，这真的太不可思议了。所以 Dobby 负责管理房子。我通过 WhatsApp 与它交流。拥有这些维护我房子的宏观动作真的很有趣。我还没有把它推向更远的地方，我想人们正在用它做更多疯狂的事情。但对我来说，即使只是家庭自动化设置，我以前要用六个完全不同的 App，现在我不再需要用这些 App 了。Dobby 用自然语言控制一切。这太神奇了。所以我觉得我甚至还没有完全推开这个范式，但它已经如此有用且令人振奋。
高晴的声音朗读： 你认为这是否预示着人们从用户体验角度对软件的需求？因为我觉得人们往往忽略了人类学习新软件、新 UI 是需要付出努力的。
苏哲的声音朗读： 是的，在某种程度上是对的。这有点像是从人们认为 AI 应该是什么样子倒推回来的。因为人们心中认为的 AI 并不是 LLM 的原始状态——LLM 在原始意义上是一个 token 生成器，它只是输出更多 token。但人们想到的是这种具有人格身份的实体，他们可以告诉它事情，它能记住，它就像 WhatsApp 背后的一个实体。这更容易理解。
苏哲的声音朗读： 所以我认为在某种程度上，这符合人类已经拥有的对 AI 行为的预期，但在底层，这涉及很多技术细节。对于大多数人来说，LLM 作为一种原始原语，还不足以被直接视为 AI。
高晴的声音朗读： 是的。我认为这就是我们理解 AI 的方式，将其描述为 Dobby 或某种性格显然能引起人们的共鸣。我也认为，你对家庭自动化中六个不同软件系统的统一，说明了一个不同的问题：人们真的需要我们今天拥有的所有这些软件吗？
苏哲的声音朗读： 是的。
高晴的声音朗读： 因为我会辩称，你拥有硬件，但你现在抛弃了软件，或者说抛弃了它的 UX 层。你认为这就是人们想要的吗？
苏哲的声音朗读： 是的。我认为有这样一种感觉，即应用商店里那些用于控制智能家居设备的 App，在某种意义上甚至不应该存在。难道不应该只有 API，然后由智能体直接使用吗？我不就可以做各种各样的家庭自动化，而任何单独的 App 都做不到吗？LLM 实际上可以驱动工具，调用所有正确的工具，做非常复杂的事情。
苏哲的声音朗读： 所以在某种意义上，它确实指向了这一点：也许存在大量不该存在的定制化、专门化的 App，因为智能体可以把它们“揉碎”，一切都应该更多地暴露为 API 端点，而智能体是智能的粘合剂，负责调用所有的部分。另一个例子是我的跑步机。我的跑步机有一个 App，我想记录我做有氧运动的频率。但我不想登录 Web UI，走一遍流程等等。所有这些都应该只是让 API 可用。这正是迈向“智能体优先”的 Web 或工具的方向。
苏哲的声音朗读： 所以我认为整个行业必须以多种方式重新配置，客户不再是人类，而是代表人类行动的智能体。这种重构在某种意义上将是实质性的。人们有时会反驳这一点，说：“我们能指望普通人去‘Vibe Coding’（凭直觉编码）这些工具吗？”
苏哲的声音朗读： 但我认为在某种程度上，这就是今天存在的科技。现在确实有一些 Vibe Coding，我也在观察并与系统合作。但我确实觉得我刚才谈到的这些东西，在一年、两年或三年内应该是免费的。不需要 Vibe Coding，这是微不足道的，是基本要求。任何 AI，甚至是开源模型等，都能做到这一点。你应该能够非常容易地将一个技术水平较低的人类的意图转化为这些操作。
高晴的声音朗读： 非常容易。今天涉及 Vibe Coding，没有多少人会去做。但你仍然需要做一些设计决策，对吧？我们刚才谈到，比如你以框架为例。
苏哲的声音朗读： 是的。但我确实觉得障碍会逐渐降低，它只是代表你运行的临时软件，某种“Claw”会为你处理所有的细节，而你不需要参与。Claw 有一台机器，它会搞定一切，它只是向你展示 UI，而你只需要说话。
高晴的声音朗读： 为什么你没有进一步推向个人使用 Claw 的界限？是因为你专注于更重要的项目，比如自动化研究（AutoResearch）之类的，还是你正在攀登通往精通的山峰，或者别的什么？
苏哲的声音朗读： 是的。我只是觉得我被一切事情分散了注意力。我在 Claw 的事情上花了一个星期，我还有更多事情要做。但我会说，我们都只是不幸地变得更忙了。是的，我还没有真正利用很多关于电子邮件、日历和所有其他东西的功能，我没有给它访问权限，因为我仍然有点怀疑，而且它还非常新，不够完善。所以我还不想给它完全访问我数字生活的权限。部分原因是出于安全、隐私和在这个领域的极度谨慎。所以我想其中一些是被这一点阻碍了。是的，也许那是主导因素，但部分原因也是我感到分心，因为我觉得我研究了一个星期的 Claw，然后其他事情又发生了。
高晴的声音朗读： 你谈到能够训练或至少优化模型是你想看到智能体完成的任务，这已经很久了。那么自动化研究（AutoResearch）背后的动机是什么？
苏哲的声音朗读： 自动化研究。是的。我想我之前发过一条推文，意思大概是：要充分利用现在可用的工具，你必须把自己从瓶颈中移除。你不能在那儿提示下一件事，你需要把自己抽离出来。你必须安排好一切，使它们完全自主，你越是——你知道的，你如何最大化你的 token 吞吐量而不参与其中？这就是目标。
苏哲的声音朗读： 所以我提到，现在的游戏规则是增加你的杠杆。我只需要偶尔投入极少的 token，就会有大量的事情代表我发生。所以自动化研究——我发了那条推文，我想人们很喜欢，但他们可能还没有深入思考其中的含义。对我来说，自动化研究就是其中的一个例子。

苏哲的声音朗读： 我们目前有大量的数字工作，是因为我们在集体思考已经数字化的内容方面存在“滞后”。我们人类没有足够的思考周期去处理已经数字化并上传的所有信息。所以我们最终会用完那些已经上传的内容。在某个时刻，你会读完所有的论文并处理它们，对尝试什么有一些想法。但我其实不知道，如果只是利用现有的信息，智能在多大程度上能完全封闭地提升。
苏哲的声音朗读： 所以我认为会发生的是：首先会有大量的解除束缚，那里有巨大的工作量。然后，它会转向物理和数字之间的界面。那就是传感器（感知世界）和执行器（对世界做些什么）。我认为很多有趣的公司会从那个界面产生：我们能否为超级智能提供某种意义上的数据，我们能否提取数据并按照它的意愿去操纵物理世界（如果你想把整件事拟人化的话）。
苏哲的声音朗读： 然后是物理世界。我几乎觉得，就工作量等方面而言，总目标市场（TAM）是巨大的，甚至可能比数字空间能发生的还要大得多。所以我认为这也是一个更大的机会。但我确实觉得这需要巨大的工作量，在我的脑海中，原子就是比比特难一百万倍。所以它会滞后，但它也是一个更大的市场。所以机会大致遵循这样的轨迹：现在数字是我的主要兴趣，然后是界面，最后可能是物理方面的事情。它们的时代会到来，当它们到来时，规模会非常巨大。
高晴的声音朗读： 这是一个有趣的框架。因为某些事情——虽然不是我目前正在做的——但在原子世界中某些事情要容易得多，对吧？如果你只是考虑对物理世界的“读”和“写”。“读”比如传感器、摄像头，已经有很多现有的硬件了。你可以想象，如果你足够聪明，你可以增强智能体的能力或捕获大量新数据，而且你不一定需要投入很多就能获得有价值的东西。

苏哲的声音朗读： 所以我认为教育将被此大幅重新洗牌，这几乎是“互相教导”的终结。比如我有一个代码库，以前会有给其他人看的文档，但你不该再那样做了。你不应该为人类准备 HTML 文档，而应该为智能体准备 Markdown 文档。因为如果智能体懂了，它们就能解释所有的部分。这是通过智能体进行的重定向。我想我们会看到更多这样的情况。
高晴的声音朗读： 我们拭目以待，看看伟大的老师们是否知道如何以不同的方式培养向智能体解释事物的直觉。
苏哲的声音朗读： 最终，比如 microGPT，我曾试着让智能体去写 microGPT。我告诉它：“试着提炼最简单的东西，试着把神经网络提炼到最简单的形式。”它做不到。microGPT 是我执念的终点。它是那 200 行。我思考了很久，痴迷了很久。这就是解决方案。相信我，它不能更简单了。这就是我的价值所在。其他的一切，智能体都能懂。
苏哲的声音朗读： 它只是想不出来。但它完全理解，也明白为什么要以某种方式去做。所以我的贡献就是这几个比特（bits），但之后发生的所有教育工作就不再是我的领地了。所以教育在这些方面发生了改变：你必须注入一些你强烈感受到的关于教学大纲或更好的解释方式的想法。智能体做不到的事情，现在就是你的工作。智能体能做的事情，它们可能比你做得更好，或者很快就会。所以你应该在时间的分配上具有战略眼光。
